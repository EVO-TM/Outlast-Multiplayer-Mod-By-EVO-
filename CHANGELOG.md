# Changelog

## 0.2.1 — 2026-10-31 — Experimental release

- Refreshed installer layout and Evo Corp application metadata.
- Game-folder detection without a personal computer path.
- Runtime-only package with no project source code.
- Backup before upgrading a recognized older mod DLL.
- Installation guides, issue forms, test coverage and SHA-256 checksums.
- English installer/launcher added alongside the original Turkish package; public documentation and release notes are English-first.
- Steam play recorded as a project-owner report, with the current executable-fingerprint limitation documented.
- Project-owner-supplied promotional cover added.
- Gameplay DLL remains byte-identical to 0.2; network protocol and save format are unchanged.

This release does not include the unpublished animation/model fixes, an FPS unlock or Cloudflare/server integration. In-game co-op labels remain Turkish.

## 0.2 — Earlier test build
