# Feedback and support

This repository accepts user reports and feature suggestions. The implementation remains private, so it is not a public source-contribution repository.

Before opening a report, check [known issues](docs/KNOWN-ISSUES.md) and [existing issues](https://github.com/EVO-TM/evo-outlast/issues). Include your game store/build, mod version, player count, host/guest role, connection method and reproduction steps. Describe expected and actual behavior separately.

For Steam compatibility, include the game file version and SHA-256 of `OLGame.exe` if possible. Do not upload the game executable. Remove IP addresses, room codes, private paths and credentials before sharing logs. Screenshots or short recordings can help explain animation or interaction issues.

For feature requests, explain the player need and expected behavior. A feature being discussed or planned does not mean it is included in the current release.
